- style.css        Design commun responsive
- script.js        Menu, validation et préparation du message WhatsApp

LANCEMENT LOCAL
1. Extraire le ZIP dans un dossier.
2. Ouvrir ce dossier avec Visual Studio Code.
3. Ouvrir index.html dans un navigateur, ou utiliser l'extension Live Server.

CONFIGURER WHATSAPP
Dans script.js, remplacer 21600000000 par le numéro professionnel, au format international, sans +, espace ni tiret.

AVANT UN VRAI LANCEMENT
- Remplacer les coordonnées, tarifs et contenus fictifs.
- Vérifier l'autorisation d'utiliser chaque photo et la licence applicable. Les images Unsplash sont chargées depuis Internet.
- Tester tous les liens et le formulaire sur téléphone et ordinateur.
- Le formulaire prépare un message WhatsApp; il ne réserve pas automatiquement un créneau et ne stocke aucune donnée.

PUBLICATION GRATUITE AVEC GITHUB PAGES
1. Créer un compte GitHub puis un dépôt public.
2. Envoyer tous les fichiers HTML, CSS et JS à la racine du dépôt.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Attendre le déploiement puis ouvrir l'URL fournie par GitHub Pages.

DEMO FICTIVE
Maison Éclat, adresse, tarifs et contact sont des exemples et ne représentent pas un établissement réel.
